# 安装指南

## 前置要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 |
| 权限 | 管理员账号（装计划任务需要） |
| .NET | **不需要**（引擎单文件自带运行时） |
| AutoCAD | 可选，2018（R22.0）已支持；没有也能装引擎 |
| 网络 | 不需要（纯规则模式离线可用） |

## 三步安装

1. 从 [Releases](https://github.com/oMrCat/cad-smart/releases/latest) 下载 `CadSmart-离线安装包.zip`，解压到任意位置
2. 右键 `install.cmd` → **以管理员身份运行**
3. 看到"安装完成"即可（约 10 秒）

### install.cmd 自动做了什么

| 步骤 | 落点 |
|------|------|
| 复制引擎 | `C:\CadSmart\server\CadSmart.Server.exe`（60MB 单文件） |
| 写启动脚本 | `C:\CadSmart\server\start-server.cmd` |
| 注册开机自启 | 计划任务 `CadSmartServer`（登录 Windows 自动启动） |
| 检测 AutoCAD | 找到 `C:\Program Files\Autodesk\AutoCAD*` 或 `D:\AutodeskCAD*\AutoCAD*` 即装插件 |

### 验证

浏览器打开 `http://127.0.0.1:46200/health` → 看到 `{"ok":true}` 即成功。

## AutoCAD 插件的安装时机

- **install.cmd 会自动检测**：如果装 install.cmd 时机器上已有 AutoCAD，插件一并装好
- **后来才装 AutoCAD**：再双击一次 `install-autocad-plugin.cmd` 即可
- 插件按 AutoCAD 2018（R22.0）编译；其他版本需要换对应 acmgd 引用重新编译（见开发者指南）

## 卸载

右键 `uninstall.cmd` → 管理员运行。清理：计划任务、`C:\CadSmart` 目录、AutoCAD 注册表加载项与 Support 里的插件 DLL。

只想关闭开机自启但保留功能：任务计划程序 → `CadSmartServer` → 禁用（不删除）。
