## 快速开始

```bash
# 1. 下载 Release 里的 CadSmart-离线安装包.zip 并解压
# 2. 右键 install.cmd → 以管理员身份运行
# 3. 打开 AutoCAD → 输入 CADSMARTON → 浮窗输入 "画个圆"
```
