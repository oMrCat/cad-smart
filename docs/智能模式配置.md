# 智能模式配置

引擎**自动探测环境、三档自动降级**，零配置即可用。想解锁语义理解再往下配。

## 三档模式

| 模式 | 触发条件 | 能力 |
|------|---------|------|
| 纯规则 | 什么都没配（默认） | 拼音/首字母/别名/关键词/模糊，离线可用，<10ms |
| 本地语义 | 局域网内有 OpenAI 兼容推理服务（LocModel/llama-server/Ollama/LM Studio） | + 自然语言理解，数据不出内网 |
| 云端语义 | 配置云端 API | + 自然语言理解，走云端算力 |

查询当前模式：浏览器开 `http://127.0.0.1:46200/llm/status`，看 `Mode` 字段。

## 配置方式

所有配置都在 `C:\CadSmart\server\start-server.cmd`（启动脚本的环境变量）。改完**重启引擎**：任务管理器结束 `CadSmart.Server.exe` → 任务计划程序运行 `CadSmartServer`。

### 方案 A：连局域网大模型（推荐，数据不出内网）

```bat
set CADSMART_LLM_HOST=192.168.1.111
set CADSMART_LLM_PORTS=18686
set CADSMART_LLM_WAITMS=45000
set no_proxy=*
```

- `HOST`：跑大模型的那台电脑 IP（本机就填 127.0.0.1）
- `PORTS`：推理端口（llama-server 默认 8080，LocModel 8686）
- `WAITMS`：等大模型结果的窗口。CPU 模型建议 45000；嫌慢调小（超时自动降级纯规则，不会出错）

### 方案 B：云端 API（DeepSeek/通义/月之暗面等）

```bat
set CADSMART_LLM_ENDPOINT=https://api.deepseek.com/v1/chat/completions
set CADSMART_LLM_MODEL=deepseek-chat
set CADSMART_LLM_APIKEY=sk-你的密钥
```

## 融合机制（规则 + LLM）

引擎不是"二选一"，是**双通道融合**：

1. 规则引擎先跑（<10ms），出 Top-N 候选
2. 若配置了 LLM：粗筛 30 条候选表发给大模型精排（约束在 1k token 内，CPU 模型也要数秒）
3. `waitMs` 窗口内 LLM 返回 → 与规则结果融合（`source=both`，如 画个圆 → CIRCLE score 88→96）
4. 窗口超时 → 纯规则结果 + `LlmDegraded=true`（**永远不会出空结果**）

`waitMs` 也可按请求覆盖：`POST /suggest {"input":"...","waitMs":8000}`（上限 60000）。

## 模型推荐

| 场景 | 推荐 | 说明 |
|------|------|------|
| 内网有现成 llama-server | 直接连 | CadSmart 只需 OpenAI 兼容 API |
| 自己装推理 | [LocModel](https://locmodel.com/) | 中文界面一键装，自动识别硬件 |
| 云端 | DeepSeek / Qwen API | 几块钱能用很久，延迟 1~3 秒 |
| GPU | CUDA ≥12GB 显存跑 4B 模型 | 1~3 秒出结果 |
