# 使用指南

## 三条命令

| 命令 | 作用 |
|------|------|
| `CADSMARTON` | 启动智能浮窗（输入框 + 候选列表） |
| `CS` | 命令行版语义搜索（不弹窗，命令行内问答） |
| `CADSMARTOFF` | 关闭浮窗 |

## 浮窗交互

```
CADSMARTON 回车
  ↓ 浮窗弹出（置顶，跟随 AutoCAD 主窗口）
输入: 画个圆
  ↓ 150ms 防抖后查询引擎，候选列表出现：
      CIRCLE  圆  (score 92)
      ARC     圆弧 (score 85)
      FILLET  圆角 (score 84)
双击 CIRCLE（或选中按回车）
  ↓ AutoCAD 开始执行画圆（等同手输 CIRCLE）
```

### 输入技巧

| 输入 | 命中 | 匹配方式 |
|------|------|---------|
| `line` | LINE | 精确命令名 |
| `l` | LINE | 快捷别名 |
| `yuan` | CIRCLE | 全拼 |
| `zx` | LINE | 拼音首字母 |
| `zixian` | LINE | 方言变体（zh→z） |
| `画个圆` | CIRCLE | 中文关键词（纯规则） |
| `把窗户都删掉` | ERASE | 语义理解（需接大模型） |

### CS 命令行版（不弹窗）

```
命令: CS
CadSmart 输入命令描述: 标尺寸
  [1] DIMLINEAR  [2] QDIM  [3] DIMEDIT ...
选择命令编号: 1
→ DIMLINEAR
```

## 上下文推荐

引擎学习命令序列：执行完 CIRCLE（画圆）后调用 `/next` 会推荐 OFFSET（偏移）——画完圆偏移一份是最常见的工作流。浮窗底部展示"下一步建议"。

## 检查引擎状态

| 地址 | 内容 |
|------|------|
| `http://127.0.0.1:46200/health` | `{"ok":true}` 即存活 |
| `http://127.0.0.1:46200/llm/status` | 当前智能模式（pure/local/cloud） |
| `http://127.0.0.1:46200/gpu/status` | GPU 型号、显存、加速判定原因 |
