# 架构设计

## 总体架构

```
┌─────────────────────────────────────────────┐
│  CAD 平台薄壳（AutoCAD 2018 已实现）          │
│  CADSMARTON/CS 命令 · WPF 浮窗 · HTTP 调用   │
└──────────────────┬──────────────────────────┘
                   │ localhost HTTP (127.0.0.1:46200)
┌──────────────────▼──────────────────────────┐
│  CadSmart.Server（引擎服务，单文件免安装）      │
│  MiniHttpServer + InProcessSuggestionEngine  │
└──────┬───────────────┬──────────────────────┘
       │               │
┌──────▼──────┐ ┌──────▼──────────────────────┐
│ CadSmart.Core│ │ CadSmart.Data               │
│ 平台无关核心  │ │ 186 条命令知识库 + 行为统计    │
└──────┬──────┘ └─────────────────────────────┘
       │ OpenAI 兼容 API（自动探测端口）
┌──────▼──────────────────────────────────────┐
│  LLM: LocModel / llama-server / 云端 API      │
└─────────────────────────────────────────────┘
```

**核心设计原则：所有智能逻辑在 `CadSmart.Core`（平台无关类库），CAD 平台只是薄壳适配器。**

## 匹配引擎（六路规则）

`MatchEngine` 按优先级跑六路匹配，全部 <10ms：

| 路 | 匹配方式 | 例 | 分值 |
|----|---------|-----|------|
| 1 | 精确命令名 | line → LINE | 100 |
| 2 | 快捷别名 | l → LINE, c → CIRCLE | 95 |
| 3 | 全拼 | yuan → CIRCLE | 92 |
| 4 | 拼音首字母 | zx → LINE | 90 |
| 5 | 关键词 | 画圆 → CIRCLE | 88 |
| 6 | 模糊/包含 | sanchu → ERASE（方言变体 sh→s） | 82+ |

中文条目带 `Pinyin` / `PinyinInitials` 预计算字段，方言变体在拼音生成时做映射（zh→z、sh→s、ch→c）。

## LLM 双通道融合

```
suggest(input)
  ├─ 通道1: 规则匹配 (<10ms) ──┐
  │                            ├─ WhenAny(waitMs 窗口)
  └─ 通道2: LLM 精排 ──────────┘
       ├─ 粗筛规则 Top30 作为候选范围（控制 prompt <1k token）
       ├─ 发给大模型（OpenAI 兼容 chat/completions）
       ├─ 窗口内返回 → 与规则融合（同命令加权，source=both）
       └─ 超时 → LlmDegraded=true，纯规则结果照常返回
```

关键参数 `waitMs`：等待窗口（默认由启动脚本设，请求可覆盖，上限 60s）。**永不阻塞规则结果**。

## 个性化与上下文

- **UsageCount**：`/accept` 记录使用次数，排序加权（越用越靠前）
- **usage.json**：30 秒定时保存 + 进程退出保存，强杀不丢
- **上下文推荐**：`/next` 基于最近命令序列（如 CIRCLE→OFFSET）推荐下一步

## GPU 加速判定

见 [GPU 加速](https://github.com/oMrCat/cad-smart/wiki/GPU-%E5%8A%A0%E9%80%9F)。nvidia-smi + 进程命令行识别，避免 WMI 程序集部署依赖。

## 平台适配器（薄壳）

```
ICommandSink / ISuggestionUI / IPlatformAdapter  ← Core 抽象
    ├── CadSmart.Adapter.AutoCAD   AutoCAD 2018（LSP + .NET 真机插件）
    ├── CadSmart.Adapter.ZWCAD     中望 CAD（ZRX 骨架）
    └── CadSmart.Adapter.GstarCAD  浩辰 CAD（GRX 骨架）
```

薄壳只做三件事：命令注册、输入捕获、SendStringToExecute 执行。所有智能逻辑都在 Core。

## 安全设计

- 引擎仅绑定 `127.0.0.1`（不对外网暴露）
- 无 SQL / 无 SHELL 路径，注入载荷作为普通文本处理
- 输入长度无上限（100KB 实测无害）
- 非法 JSON 返回空结果不崩溃
