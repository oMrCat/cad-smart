# 开发者指南

## 环境要求

| 工具 | 版本 | 用途 |
|------|------|------|
| .NET SDK | 8.0+ | 编译（项目多目标 net8.0 + net6.0） |
| Git | 任意 | 版本管理 |
| AutoCAD 2018 | 可选 | 真机插件编译（需要 acmgd/acdbmgd/accoremgd.dll） |

## 克隆与构建

```bash
git clone https://github.com/oMrCat/cad-smart.git
cd cad-smart

# 还原 + 编译（全部项目）
dotnet build CadSmart.sln

# 跑测试（105 项）
dotnet test tests/CadSmart.Core.Tests
```

## 发布引擎

```bash
# 普通（目标机需 .NET 6+ 运行时）
dotnet publish src/CadSmart.Server -c Release -f net6.0 -o dist/server-net6
dotnet publish src/CadSmart.Server -c Release -f net8.0 -o dist/server

# 自包含单文件（目标机免装 .NET，推荐用于安装包）
dotnet publish src/CadSmart.Server -c Release -f net6.0 -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -o dist/server-selfcontained
```

## 编译 AutoCAD 真机插件

插件按 net48 编译，引用 AutoCAD 安装目录下的三个程序集：

1. 从 AutoCAD 2018 安装目录复制 `acmgd.dll`、`acdbmgd.dll`、`accoremgd.dll` 到 `lib/autocad2018/`（lib/ 已 gitignore）
2. 构建：

```bash
dotnet build src/CadSmart.Adapter.AutoCAD/CadSmart.Adapter.AutoCAD.Real.csproj
```

3. 产物 `bin/Debug/net48/CadSmart.Adapter.AutoCAD.Real.dll` + 依赖 DLL 一起部署到目标机

> 引用程序集在编译机不需要装 AutoCAD，只需那三个 DLL 文件。`Private=false` 确保 NETLOAD 时用 AutoCAD 自带版本。

## AutoCAD 插件真机部署

方式一：NETLOAD 手动加载（开发期）

```
NETLOAD → 选 CadSmart.Adapter.AutoCAD.Real.dll → CADSMARTON
```

方式二：注册表自动加载（发布版，install.cmd 自动做）

```
HKLM\SOFTWARE\Autodesk\AutoCAD\R22.0\ACAD-xxxx:804\Applications\CadSmart
  LOADCTRLS = 2 (DWORD, 命令调用时按需加载)
  LOADER    = C:\CadSmart\autocad-net\CadSmart.Adapter.AutoCAD.Real.dll
  COMMANDS  = CADSMARTON
```

无头验证（不启动图形界面）：

```bash
accoreconsole.exe /i 测试图.dwg /s 脚本.scr /l
# 脚本.scr 内容:
#   NETLOAD C:\CadSmart\autocad-net\CadSmart.Adapter.AutoCAD.Real.dll
#   CADSMARTOFF
```

## AutoCAD 2018 API 差异清单（踩坑记录）

| 新版 API | 2018 写法 |
|---------|----------|
| `PromptStringResult.Value` | `GetString(...).StringResult`（直接是 string） |
| `Editor.GetKeyedKeywords` | 不存在，用 GetString 数字选择 |
| `SendStringToExecute(s, activate)` | 4 参必填 `(s, activate, wrapUpInactiveDoc, echoCommand)` |
| `Application` | 与 WPF `Application` 冲突，需全限定 `Autodesk.AutoCAD.ApplicationServices.Application` |
| `PaletteSet` 承载 WPF | 需 WinForms ElementHost 互操作；简化方案：无模式 WPF Window + WindowInteropHelper.Owner 绑定主窗口 |

## 适配新 CAD 平台（中望/浩辰）

1. 新建 `CadSmart.Adapter.XXX` 项目，实现 Core 的 `IPlatformAdapter`
2. 参照 `CadSmart.Adapter.AutoCAD/RealAdapter.cs` 的薄壳模式：命令注册 + 输入捕获 + HTTP 调引擎
3. 引擎是独立进程，适配器只需 HTTP 客户端（见 `EngineClient.Suggest/Accept`）

## 项目约定

- 所有控制台输出走 `SafeLog`（托管运行时 stdout 管道可能断裂）
- HTTP 路由在 `MiniHttpServer.HandleAsync`，新端点加 case
- 知识库 `commands.json` 内嵌为资源；`KnowledgeUpdater` 支持 SHA256 校验 + 原子替换
- 提交信息格式：`<模块>：<改动>（可选：真机验证结果）`

## 已知技术债

- `net6.0` 目标已 EOL（为兼容远程机保留，可移除）
- LSP 版插件（`cadsmart.lsp`）是早期占位，.NET 真机插件（`RealAdapter.cs`）为主力
- 命令行逐字实时候选需 WH_KEYBOARD 钩子（路线图待做）
